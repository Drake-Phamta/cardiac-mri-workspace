# Practice — Nguyễn Gia Đức Trung

## Mục đích

Luyện quy trình tạo thay đổi nhỏ, kiểm tra và gửi review.

## Thay đổi

- Tôi đang làm quen với quy trình Git/PR.
- Tôi hiểu rằng chỉ được commit các file thuộc công việc của mình.
- Tôi không dùng `git add .` khi repository còn thay đổi không liên quan.

## Kiểm tra

- [ ] Đã kiểm tra nội dung file.
- [ ] Đã kiểm tra diff.
- [ ] Không ghi đè file gốc.
