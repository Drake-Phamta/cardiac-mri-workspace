### NON-BLOCKING findings
Each finding below was probed by mutation on the merged tree.

- **N-1. The new test "every contract error code reads as words" (V3S10) is vacuous.**
  - `reasonLabel` now turns any ALL_CAPS code into words. Deleting `STALE_REVISION`, `GEOMETRY_NOT_VALIDATED` or `VALIDATION_ERROR` from `REASON` leaves every test green, so nothing holds the 15 + 3 sentences.
  - Fix: assert that each code has its own `REASON` entry (export a helper), or assert the literal sentence.
- **N-2. The SCR-01 headline summaries have no screen-level check.**
  - Removing the one line that draws `summaryRows` in `StudyOverviewScreen.js` leaves the render smoke green (205/205), so the PR's only UI change is unchecked.

  - The reason "server did not confirm the per-case variant" is untested.
  - The `disabledIntentReason` passthrough of `readCaseRows` is held by the mobile test but not by the model suite (160/160).
